# Results Directory

This directory contains all outputs from training and evaluation.

## Structure

```
results/
├── visualizations/          # Generated plots and figures
│   ├── confusion_matrix.png
│   ├── training_history.png
│   ├── classwise_f1_scores.png
│   └── training_summary.png
│
└── metrics/                 # Performance metrics and logs
    ├── evaluation_metrics.txt
    ├── training_history.csv
    └── hyperparameters_log.json
```

## Visualizations

### 1. `confusion_matrix.png`
Heatmap showing predicted vs. actual fault classifications for all 6 classes.

### 2. `training_history.png`
Training and validation curves showing:
- Accuracy over epochs
- Loss over epochs

### 3. `classwise_f1_scores.png`
Horizontal bar chart comparing F1 scores across all fault types.

### 4. `training_summary.png`
Quick 2-panel summary of training progress (accuracy and loss).

## Metrics

### 1. `evaluation_metrics.txt`
Detailed text report containing:
- Overall accuracy, precision, recall, F1-score
- Class-wise classification report
- Confusion matrix statistics

### 2. `training_history.csv`
CSV file with epoch-by-epoch metrics:
- Columns: `epoch`, `loss`, `accuracy`, `val_loss`, `val_accuracy`
- Useful for plotting custom training curves

### 3. `hyperparameters_log.json`
Complete record of all hyperparameters used for training:
- Model architecture parameters
- Training configuration
- Data preprocessing settings
- Timestamp for reproducibility

## Usage

All files in this directory are automatically generated by:
- `train_cnn_lstm.py` → Creates training artifacts
- `evaluate_model.py` → Creates evaluation artifacts

To regenerate all results:
```bash
cd ../src
python train_cnn_lstm.py
python evaluate_model.py
```
